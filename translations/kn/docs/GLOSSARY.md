## ಮುಖ್ಯ ತತ್ವಗಳು

**AI ಏಜೆಂಟ್** - AI ಬಳಸಿಕೊಂಡು ಸ್ವಯಂಚಾಲಿತವಾಗಿ ಯೋಚನೆ ಮತ್ತು ಕಾರ್ಯನಿರ್ವಹಿಸುವ ವ್ಯವಸ್ಥೆ. [ಮಾಡ್ಯೂಲ್ 04](../04-tools/README.md)

**ಚೈನ್** - ಕ್ರಮವಾಗಿ ನಡೆಯುವ ಕಾರ್ಯದ ಸಾಲು, ಹೊರತುಪಡಿಸಿ ಮುಂದಿನ ಹಂತಕ್ಕೆ ಇತ್ಯರ್ಥ ನೀಡಿ.

**ಚಂಕಿಂಗ್** - ದಸ್ತಾವೇಜುಗಳನ್ನು ಸಣ್ಣ ತುಂಡುಗಳಾಗಿ ವಿಭಜಿಸುವುದು. ಸಾಮಾನ್ಯ: 300-500 ಟೋಕನ್ಸ್ ಮೇಲೆ ನಡೆಯುತ್ತದೆ. [ಮಾಡ್ಯೂಲ್ 03](../03-rag/README.md)

**ಸಾಂದರ್ಭಿಕ ವಿಂಡೋ** - ಮಾದರಿ ಪ್ರಕ್ರಿಯೆಸಬಹುದಾದ ಗರಿಷ್ಠ ಟೋಕನ್ಸ್. GPT-5.2: 400K ಟೋಕನ್ಸ್ (ಗರಿಷ್ಠ 272K ಇನ್‌ಪುಟ್, 128K ಔಟ್‌ಪುಟ್).

**ಎಂಬೆಡ್ಡಿಂಗ್ಸ್** - ಪಠ್ಯದ ಅರ್ಥವನ್ನು ಪ್ರತಿನಿಧಿಸುವ ಸಂಖ್ಯಾತ್ಮಕ ವೆಕ್ಟರ್‌ಗಳು. [ಮಾಡ್ಯೂಲ್ 03](../03-rag/README.md)

**ಫಂಕ್ಷನ್ ಕರೆ** - ಮಾದರಿ ಬಾಹ್ಯ ಕಾರ್ಯಗಳನ್ನು ಕರೆ ಮಾಡುವುದು ಈಡೇರಿಸುವ ರಚನಾತ್ಮಕ ವಿನಂತಿಗಳನ್ನು ತಯಾರಿಸುತ್ತದೆ. [ಮಾಡ್ಯೂಲ್ 04](../04-tools/README.md)

**ಹ್ಯಾಲ್ಯೂಸಿನೇಷನ್** - ಮಾದರಿಗಳು ತಪ್ಪಾದ ಆದರೆ ನಂಬಿಕಯೋಗ್ಯ ಮಾಹಿತಿಯನ್ನು ರಚಿಸುವಾಗ.

**ಪ್ರಾಂಪ್ಟ್** - ಭಾಷಾ ಮಾದರಿಗೆ ಪಠ್ಯ ಇನ್‌ಪುಟ್. [ಮಾಡ್ಯೂಲ್ 02](../02-prompt-engineering/README.md)

**ಸಮಾನಾರ್ಥಕ ಹುಡುಕು** - ಕೀವರ್ಡ್ ಬಳಕೆಯ ಬದಲು ಎಂಬೆಡ್ಡಿಂಗ್ಸ್ ಬಳಸಿ ಅರ್ಥದ ಮೂಲಕ ಹುಡುಕು. [ಮಾಡ್ಯೂಲ್ 03](../03-rag/README.md)

**ಸ್ಟೇಟ್‌ಫುಲ್ ವಿರುದ್ದ ಸ್ಟೇಟ್‌ಲೆಸ್** - ಸ್ಟೇಟ್‌ಲೆಸ್: ಮೇಮರಿ ಇಲ್ಲ. ಸ್ಟೇಟ್‌ಫುಲ್: ಸಂವಾದ ಇತಿಹಾಸವನ್ನು ಇಡುತ್ತದೆ. [ಮಾಡ್ಯೂಲ್ 01](../01-introduction/README.md)

**ಟೋಕನ್ಸ್** - ಮಾದರಿಗಳು ಪ್ರಕ್ರಿಯೆಸುವ ಮೂಲ ಪಠ್ಯ ಘಟಕಗಳು. ವೆಚ್ಚ ಮತ್ತು ਸੀಮಿತಗೊಳಿಸುವಿಕೆಗೆ ಪ್ರಭಾವ ಬೀರುತ್ತವೆ. [ಮಾಡ್ಯೂಲ್ 01](../01-introduction/README.md)

**ಟೂಲ್ ಚೈನಿಂಗ್** - ಕ್ರಮಬದ್ಧವಾಗಿ ಉಪಕರಣ ಕಾರ್ಯಾಚರಣೆ, ಹೊರತುಪಡಿಸಿ ಮುಂದಿನ ಕರೆಗೆ ಮಾಹಿತಿ ಒದಗಿಸುವುದು. [ಮಾಡ್ಯೂಲ್ 04](../04-tools/README.md)

## LangChain4j ಘಟಕಗಳು

**AiServices** - ಟೈಪ್-ಸೇಫಾ AI ಸೇವಾ ಇಂಟರ್ಫೇಸ್‌ಗಳನ್ನು ಸೃಷ್ಟಿಸುತ್ತದೆ.

**OpenAiOfficialChatModel** - OpenAI ಮತ್ತು ಅಜೂರ್ OpenAI ಮಾದರಿಗಳಿಗಾಗಿ ಏಕೀಕೃತ ಕ್ಲೈಂಟ್.

**OpenAiOfficialEmbeddingModel** - OpenAI ಅಧಿಕೃತ ಕ್ಲೈಂಟ್ ಬಳಸಿ ಎಂಬೆಡ್ಡಿಂಗ್ಸ್ ಸೃಷ್ಟಿಸುತ್ತದೆ (OpenAI ಮತ್ತು ಅಜೂರ್ OpenAI ಎರಡನ್ನೂ ಬೆಂಬಲಿಸುತ್ತದೆ).

**ChatModel** - ಭಾಷಾ ಮಾದರಿಗಳ ಮುಖ್ಯ ಇಂಟರ್ಫೇಸ್.

**ChatMemory** - ಸಂವಾದ ಇತಿಹಾಸವನ್ನು ಕಾಯ್ದಿರಿಸುತ್ತದೆ.

**ContentRetriever** - RAG ಗಾಗಿ ಸಂಬಂಧಿಸಿದ ದಸ್ತಾವೇಜು ಚಂಕ್‌ಗಳನ್ನು ಹುಡುಕುತ್ತದೆ.

**DocumentSplitter** - ದಸ್ತಾವೇಜುಗಳನ್ನು ಚಂಕ್‌ಗಳಾಗಿ ವಿಭಜಿಸುತ್ತದೆ.

**EmbeddingModel** - ಪಠ್ಯವನ್ನು ಸಂಖ್ಯಾತ್ಮಕ ವೆಕ್ಟರ್‌ಗಳಾಗಿ ಪರಿವರ್ತಿಸುತ್ತದೆ.

**EmbeddingStore** - ಎಂಬೆಡ್ಡಿಂಗ್ಸ್ ನ್ನು ಸಂಗ್ರಹಿಸುತ್ತದೆ ಮತ್ತು ಮರುಪಡೆಯುತ್ತದೆ.

**MessageWindowChatMemory** - ಇತ್ತೀಚಿನ ಸಂದೇಶಗಳ ಸ್ಲೈಡಿಂಗ್ ವಿಂಡೋವನ್ನು ನಿರ್ವಹಿಸುತ್ತದೆ.

**PromptTemplate** - `{{variable}}` ಪ್ಲೇಸ್‌ಹೋಲ್ಡರ್‌ಗಳೊಂದಿಗೆ ಪೂನರುಪಯೋಗಿ ಪ್ರಾಂಪ್ಟ್‌ಗಳನ್ನು ರಚಿಸುತ್ತದೆ.

**TextSegment** - ಮೆಟಾಡೇಟಾ ಹೊಂದಿದ ಪಠ್ಯ ತುಂಡು. RAG ನಲ್ಲಿ ಬಳಕೆ.

**ToolExecutionRequest** - ಉಪಕರಣ ಕಾರ್ಯನಿರ್ವಹಣೆ ವಿನಂತಿಯನ್ನು ಪ್ರತಿನಿಧಿಸುತ್ತದೆ.

**UserMessage / AiMessage / SystemMessage** - ಸಂವಾದ ಸಂದೇಶ ಪ್ರಕಾರಗಳು.

## AI/ML ತತ್ವಗಳು

**ಫ್ಯೂ-ಶಾಟ್ ಲರ್ನಿಂಗ್** - ಪ್ರಾಂಪ್ಟ್‌ಗಳಲ್ಲಿ ಉದಾಹರಣೆಗಳನ್ನು ಕೊಡುವುದು. [ಮಾಡ್ಯೂಲ್ 02](../02-prompt-engineering/README.md)

**ಲಾರ್ಜ್ ಲ್ಯಾಂಗ್ವೇಜ್ ಮಾದರಿ (LLM)** - ವಿಸ್ತೃತ ಪಠ್ಯ ಡೇಟಾ ಮೇಲೆ ತರಬೇತಿ ಪಡೆದ AI ಮಾದರಿಗಳು.

**ಯೋಚನಾ ಪ್ರಯತ್ನ** - GPT-5.2 ನಿಯಂತ್ರಿಸುವ ಯೋಚಿಸುವ ಆಳ. [ಮಾಡ್ಯೂಲ್ 02](../02-prompt-engineering/README.md)

**ತೆಂಪರೆಚರ್** - ಔಟ್‌ಪುಟ್ ಅನಿಶ್ಚಿತತೆಯನ್ನು ನಿಯಂತ್ರಿಸುತ್ತದೆ. ಕಡಿಮೆ=ನಿರ್ದಿಷ್ಟ, ಹೆಚ್ಚಿನ=ಸೃಜನಶೀಲ.

**ವೆಕ್ಟರ್ ಡೇಟಾಬೇಸ್** - ಎಂಬೆಡ್ಡಿಂಗ್ಸ್‌ಗೆ ವಿಶೇಷ ಡೇಟಾಬೇಸ್. [ಮಾಡ್ಯೂಲ್ 03](../03-rag/README.md)

**ಜೀરો-ಶಾಟ್ ಲರ್ನಿಂಗ್** - ಉದಾಹರಣೆ ಇಲ್ಲದೆ ಕಾರ್ಯಗಳನ್ನು ನಿರ್ವಹಿಸುವುದು. [ಮಾಡ್ಯೂಲ್ 02](../02-prompt-engineering/README.md)

## ರಕ್ಷಣಾ ಮಾರ್ಗಗಳು

**ಡಿಫೆನ್ಸ್ ಇನ್ ಡೆಪ್ತ್** - ಅಪ್ಲಿಕೇಶನ್-ಲೆವೆಲ್ ರಕ್ಷಣಾ ಮಾರ್ಗಗಳನ್ನು ಮತ್ತು ಪ್ರೊವೈಡರ್ ಸೆಫ್ಟಿ ಫಿಲ್ಟರ್‌ಗಳನ್ನು ಸಂಯೋಜಿಸುವ ಬಹುಮಟ್ಟದ ಭದ್ರತಾ ವಿಧಾನ.

**ಹಾರ್ಡ್ ಬ್ಲಾಕ್** - ಗಂಭೀರ ವಿಷಯ ಉಲ್ಲಂಘನೆಗಳಿಗೆ ಪ್ರೊವೈಡರ್ HTTP 400 ದೋಷ ತೋರಿಸುತ್ತದೆ.

**InputGuardrail** - LangChain4j ಇಂಟರ್ಫೇಸ್ LLM ಗೆ ಹೋಗುವ ಮೊದಲು ಬಳಕೆದಾರ ಇನ್‌ಪುಟ್ ಮಾನ್ಯತೆಗೊಳಿಸು ತುದಿಗೆ ಸೇರಿಸುವ ಮೂಲಕ ವೆಚ್ಚ ಮತ್ತು ವಿಳಂಬವನ್ನು ಉಳಿಸುತ್ತದೆ.

**InputGuardrailResult** - ಗಾರ್ಡ್ರೈಲ್ ಮಾನ್ಯತೆಯ ಪ್ರತಿಕ್ರಿಯಾ ಪ್ರಕಾರ: `success()` ಅಥವಾ `fatal("ಕಾರಣ")`.

**OutputGuardrail** - ಬಳಕೆದಾರರಿಗೆ ಹಿಂದಿರುಗಿಸುವ ಮೊದಲು AI ಪ್ರತಿಕ್ರಿಯೆಗಳನ್ನು ಮಾನ್ಯತೆಗೊಳಿಸುವ ಇಂಟರ್ಫೇಸ್.

**Provider Safety Filters** - API ಮಟ್ಟದಲ್ಲಿ ಉಲ್ಲಂಘನೆಗಳನ್ನು ಹಿಡಿಯುವ, AI ಪ್ರೊವೈಡರ್‌ಗಳಲ್ಲಿ (ಉದಾ: ಅಜೂರ್ OpenAI) ನಿರ್ಮಿತ ವಿಷಯ ಫಿಲ್ಟರ್‌ಗಳು.

**Soft Refusal** - ಮಾದರಿ ದೋಷ ತೋರಿಸುವದೆ ಇಲ್ಲದೆ ಶಿಷ್ಟವಾಗಿ ಉತ್ತರ ನೀಡಲು ನಿರಾಕರಿಸುವುದು.

## ಪ್ರಾಂಪ್ಟ್ ಎಂಜಿನಿಯರಿಂಗ್ - [ಮಾಡ್ಯೂಲ್ 02](../02-prompt-engineering/README.md)

**ಚೈನ್-ಆಫ್-ಥಾಟ್** - ಉತ್ತಮ ನಿಖರತೆಗಾಗಿ ಹಂತಬಿಡುವ ಯೋಚನೆ.

**ಬಂಧಿತ ಔಟ್‌ಪುಟ್** - ನಿರ್ದಿಷ್ಟ ರೂಪ ಅಥವಾ ರಚನೆಯನ್ನು ಅನುವರ್ಥಿಸುವುದು.

**ಹೆಚ್ಚಿನ ಉತ್ಸಾಹ** - GPT-5.2 ನ ಸಂಪೂರ್ಣ ಯೋಚನೆಗಾಗಿ ವಿನ್ಯಾಸ ಮಾಡಲಾದ ಮಾದರಿ.

**ಕಡಿಮೆ ಉತ್ಸಾಹ** - ಶೀಘ್ರ ಉತ್ತರಗಳಿಗೆ GPT-5.2 ಮಾದರಿ ಮಾದರಿ.

**ಬಹು-ತಿರುಗು ಸಂವಾದ** - ವಿನಿಮಯಗಳಲ್ಲಿ ಸಾಂದರ್ಭಿಕತೆಯನ್ನು ಕಾಪಾಡುವುದು.

**ಪಾತ್ರಾಧಾರಿತ ಪ್ರಾಂಪ್ಟಿಂಗ್** - ಸಿಸ್ಟಂ ಸಂದೇಶಗಳ ಮೂಲಕ ಮಾದರಿ ವ್ಯಕ್ತಿತ್ವವನ್ನು ಹೊಂದಿಸುವುದು.

**ಸ್ವ-ಪರಿಶೀಲನೆ** - ಮಾದರಿ ತನ್ನ ಔಟ್‌ಪುಟ್ ಬೆಲೆಮಾಚಿ ಸುಧಾರಿಸುತ್ತದೆ.

**ಸಂರಚಿತ ವಿಶ್ಲೇಷಣೆ** - ಸ್ಥಿರ ಮೌಲ್ಯಮಾಪನ ರೂಪರೇಖೆ.

**ಕಾರ್ಯ ನಿರ್ವಹಣಾ ಮಾದರಿ** - ಯೋಜನೆ → ನಿರ್ವಹಣೆ → ಸಾರಾಂಶ.

## RAG (ಮರುಪಡೆಯುವ ಅನ್ವಯ ಸಂಕಲನ) - [ಮಾಡ್ಯೂಲ್ 03](../03-rag/README.md)

**ದಸ್ತಾವೇಜು ಪ್ರಕ್ರಿಯೆ ಪೈಪ್‌ಲೈನ್** - ಲೋಡ್ → ಚಂಕ್ → ಎಂಬೆಡ್ಡ್ → ಸ್ಟೋರ್.

**ಇನ್-ಮೆಮೋರಿ ಎಂಬೆಡ್ಡಿಂಗ್ ಸ್ಟೋರ್** - ಪರೀಕ್ಷೆಗಾಗಿ ಅಸ್ಥಾಯಿ ಸಂಗ್ರಹಣೆ.

**RAG** - ಮರುಪಡೆಯುವಿಕೆಯನ್ನು ಉತ್ಪತ್ತಿಯೊಂದಿಗೆ ಸಂಯೋಜಿಸಿ ಪ್ರತಿಕ್ರಿಯೆಗಳನ್ನು ಸ್ಥಾಪಿಸುತ್ತದೆ.

**ಸಮಾನತೆ ಅಂಕ** - ಅರ್ಥ ಸಮ್ಮಿಲನದ ಮಾಪಕ (0-1).

**ಮೂಲ ಉಲ್ಲೇಖ** - ಮರುಪಡೆಯಲಾದ ವಿಷಯದ ಮೆಟಾಡೇಟಾ.

## ಏಜೆಂಟ್ಸ್ ಮತ್ತು ಉಪಕರಣಗಳು - [ಮಾಡ್ಯೂಲ್ 04](../04-tools/README.md)

**@Tool ಅಳವಡಿಕೆ** - AI ಕರೆ ಮಾಡಬಹುದಾದ ಉಪಕರಣಗಳಾಗಿ ಜಾವಾ ವಿಧಾನಗಳನ್ನು ಗುರುತುಮಾಡುತ್ತದೆ.

**ReAct ಮಾದರಿ** - ಯೋಚನೆ → ಕಾರ್ಯ → ಹಂಚಿಕೆ → ಪುನರಾವೃತ.

**ಅಧಿವೇಶನ ನಿರ್ವಹಣೆ** - ವಿಭಿನ್ನ ಬಳಕೆದಾರರಿಗಾಗಿ ಪ್ರತ್ಯೇಕ ಸಾಂದರ್ಭಿಕತೆಗಳು.

**ಉಪಕರಣ** - AI ಏಜೆಂಟ್ ಕರೆ ಮಾಡಬಹುದಾದ ಕಾರ್ಯ.

**ಉಪಕರಣ ವಿವರಣೆ** - ಉಪಕರಣ ಉದ್ದೇಶ ಮತ್ತು ಪರಿಮಾಣಗಳ ಡಾಕ್ಯುಮೆಂಟ್.

## ಏಜೆಂಟಿಕ್ ಮಾಡ್ಯೂಲ್ - [ಮಾಡ್ಯೂಲ್ 05](../05-mcp/README.md)

**@Agent ಅಳವಡಿಕೆ** - ಘೋಷಣಾತ್ಮಕ ವರ್ತನೆ ವಿಸ್ತಾರಣೆಯೊಂದಿಗೆ AI ಏಜೆಂಟ್‌ಗಳಾಗಿ ಇಂಟರ್ಫೇಸ್ ಗುರುತುಮಾಡುತ್ತದೆ.

**ಏಜೆಂಟ್ ಶ್ರೋತೃ** - `beforeAgentInvocation()` ಮತ್ತು `afterAgentInvocation()` ಮೂಲಕ ಏಜೆಂಟ್ ಕಾರ್ಯಾಚರಣೆ ಮೇಲ್ವಿಚಾರಣೆಗೆ ಹೂಕ್.

**ಏಜೆಂಟಿಕ್ ವ್ಯಾಪ್ತಿ** - ಏಜೆಂಟ್‌ಗಳು `outputKey` ಬಳಸಿ ಫಲಿತಾಂಶಗಳನ್ನು ಸಂಗ್ರಹಿಸುವ ಹಂಚಿಕೆಯ ಮೆಮೊರಿ, ಹೀಗಾಗಿ ನಂತರದ ಏಜೆಂಟ್‌ಗಳು ಬಳಸಬಹುದು.

**ಏಜೆಂಟಿಕ್ ಸೇವೆಗಳು** - `agentBuilder()` ಮತ್ತು `supervisorBuilder()` ಬಳಸಿ ಏಜೆಂಟ್‌ಗಳನ್ನು ನಿರ್ಮಿಸುವ ಫ್ಯಾಕ್ಟರಿ.

**ಶರತ್ತು ಆಧಾರಿತ ಕಾರ್ಯಪ್ರವಾಹ** - ವಿಭಿನ್ನ ವಿಶೇಷಜ್ಞ ಏಜೆಂಟ್‌ಗಳಿಗೆ ಮಾರ್ಗವನ್ನು ನಿರ್ಧರಿಸುವುದು.

**ಮಾನವ-ಇನ್-ದಿ-ಲೂಪ್** - ಮಾನವ ಪರಿಶೀಲನೆಗಳು ಅಥವಾ ವಿಷಯ ವಿಮರ್ಶೆಗಾಗಿ ಕಾರ್ಯಪ್ರವಾಹ ಮಾದರಿ.

**langchain4j-agentic** - ಘೋಷಣಾತ್ಮಕ ಏಜೆಂಟ್ ನಿರ್ಮಾಣದ ಮೇವನ್ ಅವಲಂಬನೆ (ಪ್ರಾಯೋಗಿಕ).

**ಲೂಪ್ ಕಾರ್ಯಪ್ರವಾಹ** - ಶರತ್ತು ಪೂರೈವರೆಗೆ ಏಜೆಂಟ್ ಕಾರ್ಯಾಚರಣೆಯನ್ನು ಪುನರಾವರ್ತಿಸುವುದು (ಉದಾ: ಗುಣಮಟ್ಟ ಅಂಕ ≥ 0.8).

**outputKey** - ಏಜೆಂಟಿಕ್ ವ್ಯಾಪ್ತಿಯಲ್ಲಿ ಫಲಿತಾಂಶಗಳ ಭಂಡಾರ ಸ್ಥಳವನ್ನು ಸೂಚಿಸುವ ಏಜೆಂಟ್ ಅಳವಡಿಕೆ ಪರಿಮाण.

**ಪ್ಯಾರಲಲ್ ಕಾರ್ಯಪ್ರವಾಹ** - ಸ್ವತಂತ್ರ ಕಾರ್ಯಗಳಿಗೆ ಹಲವಾರು ಏಜೆಂಟ್‌ಗಳನ್ನು samtid ಗತವಾಗಿ ಚಲಿಸುವುದು.

**ಪ್ರತಿಕ್ರಿಯೆ ಯುಕ್ತಿ** - ಮೇಲ್ವಿಚಾರಕ ಅಂತಿಮ ಉತ್ತರವನ್ನು ಹೇಗೆ ರೂಪಿಸುವುದು: LAST, SUMMARY, ಅಥವಾ SCORED.

**ಕ್ರಮಬದ್ಧ ಕಾರ್ಯಪ್ರವಾಹ** - ಕ್ರಮವಾಗಿ ಏಜೆಂಟ್‌ಗಳನ್ನು ಕಾರ್ಯಗತಗೊಳಿಸುವುದು, ಹೊರತುಪಡಿಸಿ ಔಟ್‌ಪುಟ್ ಮುಂದಿನ ಹಂತಕ್ಕೆ ಹೋಮುತ್ತದೆ.

**ಮೇಲ್ವಿಚಾರಕ ಏಜೆಂಟ್ ಮಾದರಿ** -ど a dynamic supervisor LLM decides which sub-agents to invoke്.

## ಮಾದರಿ ಸಾಂದರ್ಭಿಕ ಪ್ರೋಟೋಕಾಲ್ (MCP) - [ಮಾಡ್ಯೂಲ್ 05](../05-mcp/README.md)

**langchain4j-mcp** - LangChain4j ನಲ್ಲಿ MCP ಏಕೀಕರಣಕ್ಕಾಗಿ ಮೇವನ್ ಅವಲಂಬನೆ.

**MCP** - ಮಾದರಿ ಸಾಂದರ್ಭಿಕ ಪ್ರೋಟೋಕಾಲ್: AI ಅಪ್ಲಿಕೇಶನ್‌ಗಳನ್ನು ಬಾಹ್ಯ ಉಪಕರಣಗಳಿಗೆ ಸಂಪರ್ಕಿಸುವ ಮಾನಕ. ಒಮ್ಮೆ ನಿರ್ಮಿಸಿ ಎಲ್ಲೆಡೆ ಬಳಸಿ.

**MCP ಕ್ಲೈಂಟ್** - MCP ಸರ್ವರ್‌ಗಳಿಗೆ ಸಂಪರ್ಕಿಸಿ ಉಪಕರಣಗಳನ್ನು ಕಂಡುಹಿಡಿಯುವ ಮತ್ತು ಬಳಸುವ ಅಪ್ಲಿಕೇಶನ್.

**MCP ಸರ್ವರ್** - ವೀಕ್ಷಣೀಯ ವಿವರಣೆಗಳು ಮತ್ತು ಪರಿಮಾಣ ಸ್ಕೀಮಾಡೊಂದಿಗೆ MCP ಮೂಲಕ ಉಪಕರಣಗಳನ್ನು ಹೊರತರುವ ಸೇವೆ.

**McpToolProvider** - LangChain4j ಘಟಕ, AI ಸೇವೆಗಳು ಮತ್ತು ಏಜೆಂಟ್‌ಗಳಲ್ಲಿ ಬಳಸಲು MCP ಉಪಕರಣಗಳನ್ನು ಮುಸ್ಲಿಮಾಡುತ್ತದೆ.

**McpTransport** - MCP ಸಂವಹನದ ಇಂಟರ್ಫೇಸ್. ಅನುಷ್ಠಾನಗಳಲ್ಲಿ ಸ್ಟಿಡಿಯೋ ಮತ್ತು HTTP ಒಳಗೊಂಡಿದೆ.

**ಸ್ಟಿಡಿಯೋ ಟ್ರಾನ್ಸ್‌ಪೋರ್ಟ್** - stdin/stdout ಮೂಲಕ ಸ್ಥಳೀಯ ಪ್ರಕ್ರಿಯೆ ಸಂವಹನ. ಫೈಲ್‌ಸಿಸ್ಟಮ್ ಪ್ರವೇಶ ಅಥವಾ ಕಮಾಂಡ್ ಲೈನ್ ಉಪಕರಣಕ್ಕೆ ಅನುಕೂಲಕರ.

**ಸ್ಟಿಡಿಯೋMcpTransport** - LangChain4j ಅನುಷ್ಠಾನ, MCP ಸರ್ವರ್ ಅನ್ನು ಉಪಪ್ರಕ್ರಿಯೆಯಾಗಿ_spawn_ ಮಾಡುತ್ತದೆ.

**ಉಪಕರಣ ಪರಿಶೋಧನೆ** - ಕ್ಲೈಂಟ್ ಸರ್ವರ್‌ನಿಂದ ಲಭ್ಯವಿರುವ ಉಪಕರಣಗಳನ್ನು ವಿವರಣೆಗಳೊಂದಿಗೆ ಸೇರಿ ಪ್ರಶ್ನೆ ಮಾಡುವುದು.
