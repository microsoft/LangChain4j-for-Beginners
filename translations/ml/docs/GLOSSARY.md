## കോർ ആശയങ്ങൾ

**AI ഏജന്റ്** - സ്വയംകാരിത്വത്തോടെ തർക്കവും പ്രവർത്തനവും നടത്താൻ AI ഉപയോഗിക്കുന്ന സംവിധാനം. [മഡ്യൂൾ 04](../04-tools/README.md)

**ചെയിൻ** - പുറപ്പ് അടുത്ത ഘട്ടത്തിലേക്ക് ഫീഡ് ചെയ്യുന്ന പ്രവർത്തനങ്ങളുടെ നിര.

**Chunking** - ഡോക്യുമെന്റുകൾ ചെറുതായി വിഭജിക്കൽ. സാധാരണ: 300-500 ടോക്കണുകൾ ഒവർലാപ് സഹിതം. [മഡ്യൂൾ 03](../03-rag/README.md)

**Context Window** - ഒരേസമയം ഒരു മോഡൽ പ്രോസസ്സ് ചെയ്യാവുന്ന പരമാവധി ടോക്കണുകൾ. GPT-5.2: 400K ടോക്കണുകൾ (272K ഇൻപുട്ട് വരെ, 128K ഔട്ട്പുട്ട്).

**Embeddings** - ടെക്സ്റ്റിന്റെ അർത്ഥം പ്രതിനിധീകരിക്കുന്ന സംഖ്യാ ഭായകങ്ങളും. [മഡ്യൂൾ 03](../03-rag/README.md)

**Function Calling** - മോഡൽ ഘടനാപരമായ അഭ്യർത്ഥനകൾ സൃഷ്ടിച്ച് ബാഹ്യ ഫങ്ഷനുകൾ വിളിക്കുന്നു. [മഡ്യൂൾ 04](../04-tools/README.md)

**Hallucination** - മോഡലുകൾ തെറ്റായെങ്കിലും വിശ്വസനീയമായ വിവരങ്ങൾ ഉദ്ഭവിപ്പിക്കുമ്പോൾ.

**Prompt** - ഭാഷാ മോഡലിലേക്ക് നൽകിയ ടെക്സ്റ്റ് ഇൻപുട്ട്. [മഡ്യൂൾ 02](../02-prompt-engineering/README.md)

**Semantic Search** - കീーワードുകൾക്കുപകരം എൻബെഡിംഗുകൾ ഉപയോഗിച്ച് അർത്ഥം വഴിയുള്ള തിരയൽ. [മഡ്യൂൾ 03](../03-rag/README.md)

**Stateful vs Stateless** - Stateless: ഓർമ്മശേഷി ഇല്ലാത്തത്. Stateful: സംഭാഷണ ചരിത്രം നിലനിർത്തുന്നത്. [മഡ്യൂൾ 01](../01-introduction/README.md)

**Tokens** - മോഡലുകൾ പ്രോസസ്സ് ചെയ്യുന്ന അടിസ്ഥാന ടെക്സ്റ്റ് ഘടകങ്ങൾ. ചെലവും പരിധികളും ബാധിക്കുന്നു. [മഡ്യൂൾ 01](../01-introduction/README.md)

**Tool Chaining** - ഔട്ട്പുട്ട് അടുത്ത വിളിക്ക് വിവരം നൽകുന്ന തുടര്‍ന്നുള്ള ഉപകരണങ്ങൾ പ്രയോഗിക്കൽ. [മഡ്യൂൾ 04](../04-tools/README.md)

## LangChain4j ഘടകങ്ങൾ

**AiServices** - ടൈപ്പ്-സേഫ് AI സേവന ഇന്റർഫേസുകൾ സൃഷ്ടിക്കുന്നു.

**OpenAiOfficialChatModel** - OpenAI, Azure OpenAI മോഡലുകൾക്കുള്ള ഐക്യക്ലയന്റ്.

**OpenAiOfficialEmbeddingModel** - OpenAI ഔദ്യോഗിക ക്ലയന്റ് ഉപയോഗിച്ച് എൻബെഡിംഗുകൾ സൃഷ്ടിക്കുന്നു (OpenAI, Azure OpenAI സൗകര്യങ്ങൾ പിന്തുണയ്ക്കുന്നു).

**ChatModel** - ഭാഷാ മോഡലുകൾക്കുള്ള പ്രാഥമിക ഇന്റർഫേസ്.

**ChatMemory** - സംഭാഷണ ചരിത്രം നിലനിർത്തുന്നു.

**ContentRetriever** - RAG നിമിത്തം പ്രസക്തമായ ഡോക്യുമെന്റ് ചങ്കുകൾ കണ്ടെത്തുന്നു.

**DocumentSplitter** - ഡോക്യുമെന്റുകൾ ചങ്കുകളായി വിഭജിക്കുന്നു.

**EmbeddingModel** - ടെക്സ്റ്റിനെ സംഖ്യാ ഭാവകങ്ങളാക്കുന്നു.

**EmbeddingStore** - എൻബെഡിംഗുകൾ സൂക്ഷിക്കുകയും പുനഃപ്രാപിക്കുകയും ചെയ്യുന്നു.

**MessageWindowChatMemory** - പുതിയ സന്ദേശങ്ങളുടെ സ്ലൈഡിംഗ് വിൻഡോകൾ നിലനിർത്തുന്നു.

**PromptTemplate** - ചെറിയ കോഡ് `{{variable}}` സ്ഥലംധാരകകൾ ഉപയോഗിച്ച് വീണ്ടും ഉപയോഗിക്കാൻ സാധിക്കുന്ന പ്രോം‌പ്റ്റുകൾ സൃഷ്ടിക്കുന്നു.

**TextSegment** - മെറ്റാഡാറ്റയോടുകൂടിയ ടെക്സ്റ്റ് ചങ്ക്. RAG-യിൽ ഉപയോഗിക്കുന്നു.

**ToolExecutionRequest** - ഉപകരണ നിർവഹണ അഭ്യർത്ഥന പ്രതിനിധാനം ചെയ്യുന്നു.

**UserMessage / AiMessage / SystemMessage** - സംഭാഷണ സന്ദേശ തരം.

## AI/ML ആശയങ്ങൾ

**Few-Shot Learning** - പ്രോംപ്റ്റുകളിൽ ഉദാഹരണങ്ങൾ നൽകുന്നത്. [മഡ്യൂൾ 02](../02-prompt-engineering/README.md)

**Large Language Model (LLM)** - വിപുലമായ ടെക്സ്റ്റ് ഡാറ്റയിൽ പരിശീലിച്ച AI മോഡലുകൾ.

**Reasoning Effort** - ആലോചന ഗഹനത നിയന്ത്രിക്കാൻ GPT-5.2 ൽ പാരാമീറ്റർ. [മഡ്യൂൾ 02](../02-prompt-engineering/README.md)

**Temperature** - ഔട്ട്പുട്ട് യാദൃച്ഛികത നിയന്ത്രിക്കുന്നു. കുറവ് = നിശ്ചിതം, ഉയർന്നത് = സൃഷ്‌ടിപരമായതു.

**Vector Database** - എൻബെഡിംഗുകൾക്കായി പ്രത്യേകിച്ചുള്ള ഡാറ്റാബേസ്. [മഡ്യൂൾ 03](../03-rag/README.md)

**Zero-Shot Learning** - ഉദാഹരണങ്ങളില്ലാതെ പ്രവർത്തനങ്ങൾ നടത്തുന്നത്. [മഡ്യൂൾ 02](../02-prompt-engineering/README.md)

## Guardrails

**Defense in Depth** - അഡ്മിനിസ്ട്രേഷൻ തല ഗാർഡ്രെയ്ൽസും പ്രൊവൈഡർ സുരക്ഷാ ഫിൽട്ടറുകളും ചേർന്ന മൾട്ടി-ലെയർ സുരക്ഷ.

**Hard Block** - ഗുരുതര ഉള്ളടക്ക ചിലവുകളിൽ പ്രൊവൈഡർ HTTP 400 പിശക് നൽകും.

**InputGuardrail** - LLM-ലേക്ക് പോവുന്നതിന് മുൻപ് LangChain4j ഉപയോക്താവ് ഇൻപുട്ട് കൃത്യമായി പരിശോധിക്കുന്ന ഇന്റർഫേസ്. ഹാനികര പ്രോംപ്റ്റ് നേരത്തെ തടയുന്നതിലൂടെ ചെലവും विलംബവും കുറയ്ക്കുന്നു.

**InputGuardrailResult** - ഗാർഡ്രെയ്ൽ പരിശോധനാ ഫലം: `success()` അല്ലെങ്കിൽ `fatal("കാരണങ്ങൾ")`.

**OutputGuardrail** - ഉപയോക്താക്കൾക്ക് മറുപടി നൽകുന്നതിനുമുമ്പ് AI പ്രതികരണങ്ങൾ പരിശോധിക്കുന്ന ഇന്റർഫേസ്.

**Provider Safety Filters** - AI പ്രൊവൈഡർമാർ (ഉദാ: Azure OpenAI) API തലത്തിൽ നിയമലംഘനങ്ങൾ പിടികൂടുന്ന മുൻനിർമ്മിത ഉള്ളടക്ക ഫിൽട്ടറുകൾ.

**Soft Refusal** - മോഡൽ പിശക് കാണിക്കാതെ നന്ദിപിടിക്കുന്നത്.

## പ്രോംപ്‌റ് എഞ്ചിനീയറിംഗ് - [മഡ്യൂൾ 02](../02-prompt-engineering/README.md)

**Chain-of-Thought** - മെച്ചപ്പെട്ട കൃത്യതയ്ക്കായി ഘട്ടംഘട്ടമായ തർക്കം.

**Constrained Output** - പ്രത്യേക ഫോർമാറ്റ് അല്ലെങ്കിൽ ഘടന നിർബന്ധിക്കൽ.

**High Eagerness** - വിശദമായ ചിന്തയ്ക്കുള്ള GPT-5.2 മാതൃക.

**Low Eagerness** - വേഗത്തിലുള്ള മറുപടികൾക്കുള്ള GPT-5.2 മാതൃക.

**Multi-Turn Conversation** - സ്വഭാവങ്ങൾ സംഭാഷണ കാലാവധിയിൽ നിലനിർത്തല്.

**Role-Based Prompting** - സിസ്റ്റം സന്ദേശം വഴി മോഡലിൻറെ വ്യക്തിത്വം ക്രമീകരിക്കൽ.

**Self-Reflection** - മോഡൽ സ്വയം താല്പര്യമറിയുകയും ചെങ്കലിക്കുക.

**Structured Analysis** - സ്ഥിരം മൂല്യനിർണ്ണയ ഘടന.

**Task Execution Pattern** - പദ്ധതിയിടുക → നടപ്പാക്കുക → സംഗ്രഹിക്കുക.

## RAG (റിട്രീവൽ-ഓഗ്മെന്റഡ് ജനറേഷൻ) - [മഡ്യൂൾ 03](../03-rag/README.md)

**Document Processing Pipeline** - ലോഡ് → ചങ്ക് → എൻബെഡ് → സൂക്ഷിക്കുക.

**In-Memory Embedding Store** - ടെസ്റ്റിംഗിനായി നശിക്കുന്നതല്ലാത്ത സ്റ്റോറേജ്.

**RAG** - തിരയലുകളും ജനറേഷനുകളും കൂട്ടിച്ചേർത്ത് മറുപടികൾ ഭൂമിയാക്കുന്നു.

**Similarity Score** - സാംഹതിമാനതയുടെ അളവ് (0-1).

**Source Reference** - കിട്ടിയ ഉള്ളടക്കത്തിന്റെ മെറ്റാഡാറ്റ.

## ഏജന്റുകളും ഉപകരണങ്ങളും - [മഡ്യൂൾ 04](../04-tools/README.md)

**@Tool Annotation** - ജാവ മETHODസുകളെ AI-കൊല്ല വിളിക്കാവുന്ന ഉപകരണങ്ങളായി അടയാളപ്പെടുത്തുന്നു.

**ReAct Pattern** - തർക്കം → പ്രവർത്തനം → ശ്രദ്ധിക്കുക → ആവർത്തിക്കുക.

**Session Management** - വ്യത്യസ്ത ഉപയോക്താക്കൾക്കായി വ്യത്യസ്ത കോൺടെക്സ്‌റ്റ്.

**Tool** - AI ഏജന്റിന് വിളിക്കാവുന്ന ഫംഗ്ഷൻ.

**Tool Description** - ഉപകരണത്തിന്റെ ഉദ്ദേശവും പാരാമീറ്ററുകളും രേഖപ്പെടുത്തൽ.

## ഏജന്റിക് മഡ്യൂൾ - [മഡ്യൂൾ 05](../05-mcp/README.md)

**@Agent Annotation** - ഡിക്ലറേറ്റീവ് പെരുമാറ്റ നിർവചനത്തോടെ AI ഏജന്റുകളായി ഇന്റർഫേസുകൾ അടയാളപ്പെടുത്തുന്നു.

**Agent Listener** - `beforeAgentInvocation()` , `afterAgentInvocation()` വഴി ഏജന്റ് പ്രവർത്തനം നിരീക്ഷിക്കുന്ന ഹുക്ക്.

**Agentic Scope** - `outputKey` ഉപയോഗിച്ച് ഏജന്റുകൾ ഔട്ട്പുട്ടുകൾ സംഭരിച്ചു ഡൗൺസ്‌ട്രോം ഏജന്റുകൾ ഉപയോഗിക്കുന്ന പങ്കുവെച്ച ഓർമ്മ.

**AgenticServices** - `agentBuilder()` , `supervisorBuilder()` ഉപയോഗിച്ച് ഏജന്റുകൾ സൃഷ്ടിക്കുന്ന ഫാക്ടറി.

**Conditional Workflow** - വ്യത്യസ്ത വിദഗ്ധ ഏജന്റുകൾക്ക് വ്യത്യസ്ത ഉപനിബന്ധം അടിസ്ഥാനമായി റൂട്ടിംഗ്.

**Human-in-the-Loop** - അംഗീകാരം അല്ലെങ്കിൽ ഉള്ളടക്ക പരിശോധനയ്ക്കായി മനുഷ്യ പരിശോധന പോയിന്റുകൾ ഉൾക്കൊള്ളുന്ന പ്രവൃത്തി പാറ്റേൺ.

**langchain4j-agentic** - ഡിക്ലറേറ്റീവ് ഏജന്റ് നിർമ്മാണത്തിനുള്ള Maven ഡിപ്പൻഡൻസി (പ്രയോാഗപരിചയം).

**Loop Workflow** - ഒരു നിബന്ധന പൂരിപ്പിക്കുന്നവരെ (ഉദാ: ഗുണമേൻമ സ്കോർ ≥ 0.8) വരെ ഏജന്റ് നിർവഹണം ആവർത്തിക്കൽ.

**outputKey** - Agentic Scope ൽ ഫലങ്ങൾ സംഭരിക്കാനുള്ള ഏജന്റ് അനോട്ടേഷൻ പാരാമീറ്റർ.

**Parallel Workflow** - സ്വതന്ത്ര പ്രവർത്തനങ്ങൾക്കായി ഒരേ സമയം പല ഏജന്റുകളും പ്രവർത്തിപ്പിക്കൽ.

**Response Strategy** - സൂപ്പർവൈസർ അവസാന ഉത്തരം രൂപപ്പെടുത്തുന്ന വിധം: LAST, SUMMARY, അല്ലെങ്കിൽ SCORED.

**Sequential Workflow** - ഔട്ട്പുട്ട് അടുത്ത ഘട്ടത്തിലേക്ക് പോവുന്ന ക്രമത്തിൽ ഏജന്റുകൾ പ്രവർത്തിപ്പിക്കുക.

**Supervisor Agent Pattern** - സൂപ്പർവൈസർ LLM ഗതിപാരമുള്ളതിലായ്കെ ഏജന്റുകൾ തിരഞ്ഞെടുക്കുന്ന പ്രഗതിശീലിത ഏജന്റിക് മാതൃക.

## മോഡൽ കോൺടെക്സ്‌റ്റ് പ്രോട്ടോക്കോൾ (MCP) - [മഡ്യൂൾ 05](../05-mcp/README.md)

**langchain4j-mcp** - LangChain4j ലെ MCP ഇന്റഗ്രേഷനിനുള്ള Maven ഡിപ്പൻഡൻസി.

**MCP** - മോഡൽ കോൺടെക്സ്‌റ്റ് പ്രോട്ടോക്കോൾ: AI ആപ്പുകൾ ബാഹ്യ ഉപകരണങ്ങളുമായി ബന്ധിപ്പിക്കാൻ സാധാരണ സ്റ്റാൻഡേര്‍ഡ്. ഒറ്റ തവണ നിർമ്മിച്ച് എല്ലായിടവും ഉപയോഗിക്കുക.

**MCP Client** - MCP സർവറുകളുമായി ബന്ധപ്പെടുന്ന, ഉപകരണങ്ങൾ തേടുകയും ഉപയോഗിക്കുകയും ചെയ്യാനുള്ള ആപ്പ്.

**MCP Server** - MCP വഴിയുള്ള ഉപകരണങ്ങൾ നിർവചിക്കുകയും പരാമീറ്റർ സ്കീമ സഹായത്തോടെ സേവനം നൽകുകയും ചെയ്യുന്നു.

**McpToolProvider** - AI സേവനങ്ങൾക്കും ഏജന്റുകൾക്കുമുള്ള MCP ഉപകരണങ്ങൾ ലാങ്ക്ചെയിൻ4ജിൽ വ്രാപ്പ് ചെയ്യുന്ന ഘടകം.

**McpTransport** - MCP ആശയവിനിമയത്തിനുള്ള ഇന്റർഫേസ്. ഒരു ഘടനയും സ്‌ടാഡിയോ, HTTP ഉൾപ്പെടുന്നു.

**Stdio Transport** - stdin/stdout വഴിയുള്ള ലോക്കൽ പ്രക്രിയ ട്രാൻസ്പോർട്ട്. ഫയൽസിസ്റ്റം ആക്‌സസ് അല്ലെങ്കിൽ കമാൻഡ് ലൈൻ ഉപകരണങ്ങൾക്കായി ഉപയോഗപ്രദം.

**StdioMcpTransport** - subprocess ആയി MCP സർവർ ഉണ്ടാക്കുന്ന LangChain4j നടപ്പാക്കൽ.

**Tool Discovery** - ലഭ്യമായ ഉപകരണങ്ങൾ വിവരണങ്ങളും സ്കീമകളും കൂടി സെർവറിൽ നിന്ന് ക്ലയന്റ് ചോദിക്കുന്നത്.
