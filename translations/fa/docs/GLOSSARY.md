## مفاهیم اصلی

**عامل هوش مصنوعی** - سیستمی که از هوش مصنوعی برای استدلال و عمل خودکار استفاده می‌کند. [ماژول ۰۴](../04-tools/README.md)

**زنجیره** - دنباله‌ای از عملیات که خروجی به مرحله بعدی منتقل می‌شود.

**تکه‌بندی** - تقسیم اسناد به قطعات کوچکتر. معمولاً: ۳۰۰-۵۰۰ توکن با همپوشانی. [ماژول ۰۳](../03-rag/README.md)

**پنجره زمینه** - حداکثر توکنی که مدل می‌تواند پردازش کند. GPT-5.2: ۴۰۰ هزار توکن (تا ۲۷۲ هزار ورودی، ۱۲۸ هزار خروجی).

**بردارهای تعبیه** - بردارهای عددی که معنای متن را نشان می‌دهند. [ماژول ۰۳](../03-rag/README.md)

**فراخوانی تابع** - مدل درخواست‌های ساختار یافته برای فراخوانی توابع خارجی تولید می‌کند. [ماژول ۰۴](../04-tools/README.md)

**توهم** - زمانی که مدل‌ها اطلاعات نادرست اما قابل قبول تولید می‌کنند.

**پرامپت** - ورودی متنی به مدل زبانی. [ماژول ۰۲](../02-prompt-engineering/README.md)

**جستجوی معنایی** - جستجو بر اساس معنا با استفاده از بردارهای تعبیه، نه کلمات کلیدی. [ماژول ۰۳](../03-rag/README.md)

**حالت بدون حفظ وضعیت در مقابل حفظ وضعیت** - بدون حفظ وضعیت: بدون حافظه. حفظ وضعیت: تاریخچه مکالمه را نگه می‌دارد. [ماژول ۰۱](../01-introduction/README.md)

**توکن‌ها** - واحدهای متنی پایه که مدل‌ها پردازش می‌کنند. بر هزینه‌ها و محدودیت‌ها تأثیر می‌گذارد. [ماژول ۰۱](../01-introduction/README.md)

**زنجیره ابزار** - اجرای متوالی ابزارها که خروجی مرحله قبلی را برای مرحله بعدی استفاده می‌کند. [ماژول ۰۴](../04-tools/README.md)

## اجزای LangChain4j

**AiServices** - ایجاد رابط‌های خدمات AI نوع ایمن.

**OpenAiOfficialChatModel** - مشتری یکپارچه برای مدل‌های OpenAI و Azure OpenAI.

**OpenAiOfficialEmbeddingModel** - ایجاد بردارهای تعبیه با استفاده از مشتری رسمی OpenAI (پشتیبانی از OpenAI و Azure OpenAI).

**ChatModel** - رابط اصلی برای مدل‌های زبانی.

**ChatMemory** - حفظ تاریخچه مکالمه.

**ContentRetriever** - یافتن قطعات مرتبط سند برای RAG.

**DocumentSplitter** - تقسیم اسناد به قطعات.

**EmbeddingModel** - تبدیل متن به بردارهای عددی.

**EmbeddingStore** - ذخیره و بازیابی بردارهای تعبیه.

**MessageWindowChatMemory** - حفظ پنجره لغزنده‌ای از پیام‌های اخیر.

**PromptTemplate** - ایجاد پرامپت‌های قابل استفاده مجدد با جایگزین‌های `{{variable}}`.

**TextSegment** - قطعه متنی با فراداده. در RAG استفاده می‌شود.

**ToolExecutionRequest** - نمایانگر درخواست اجرای ابزار.

**UserMessage / AiMessage / SystemMessage** - انواع پیام مکالمه.

## مفاهیم AI/ML

**یادگیری با نمونه کم (Few-Shot Learning)** - ارائه نمونه‌ها در پرامپت‌ها. [ماژول ۰۲](../02-prompt-engineering/README.md)

**مدل زبانی بزرگ (LLM)** - مدل‌های AI آموزش دیده روی حجم زیادی از داده‌های متنی.

**تلاش استدلالی** - پارامتری در GPT-5.2 که عمق تفکر را کنترل می‌کند. [ماژول ۰۲](../02-prompt-engineering/README.md)

**دما (Temperature)** - کنترل تصادفی بودن خروجی. پایین = قطعی، بالا = خلاقانه.

**پایگاه داده برداری** - پایگاه داده تخصصی برای بردارهای تعبیه. [ماژول ۰۳](../03-rag/README.md)

**یادگیری بدون نمونه (Zero-Shot Learning)** - انجام وظایف بدون نمونه. [ماژول ۰۲](../02-prompt-engineering/README.md)

## محافظ‌ها

**دفاع در عمق** - رویکرد امنیتی چندلایه که محافظ‌های در سطح برنامه را با فیلترهای ایمنی ارائه‌دهنده ترکیب می‌کند.

**مسدودسازی سخت** - ارائه‌دهنده خطای HTTP 400 برای نقض‌های جدی محتوا صادر می‌کند.

**محافظ ورودی** - رابط LangChain4j برای اعتبارسنجی ورودی کاربر قبل از رسیدن به LLM. با مسدود کردن زودهنگام پرامپت‌های مضر، هزینه و تأخیر را کاهش می‌دهد.

**نتیجه محافظ ورودی** - نوع بازگشتی برای اعتبارسنجی محافظ: `success()` یا `fatal("reason")`.

**محافظ خروجی** - رابط برای اعتبارسنجی پاسخ‌های AI قبل از بازگشت به کاربران.

**فیلترهای ایمنی ارائه‌دهنده** - فیلترهای محتوای داخلی از ارائه‌دهندگان هوش مصنوعی (مثلاً Azure OpenAI) که نقض‌ها را در سطح API می‌گیرند.

**رد نرم** - مدل به طور مودبانه از پاسخ دادن امتناع می‌کند بدون اینکه خطا بدهد.

## مدول عامل‌محور - [ماژول ۰۵](../05-mcp/README.md)

**@Agent Annotation** - علامت‌گذاری رابط‌ها به عنوان عوامل AI با تعریف رفتاری اظهاری.

**شنونده عامل** - هوک برای نظارت بر اجرای عامل از طریق `beforeAgentInvocation()` و `afterAgentInvocation()`.

**دامنه عاملی** - حافظه مشترکی که عوامل خروجی‌ها را با استفاده از `outputKey` ذخیره می‌کنند تا عوامل پایین‌دستی مصرف کنند.

**AgenticServices** - کارخانه برای ساخت عوامل با استفاده از `agentBuilder()` و `supervisorBuilder()`.

**گردش کار شرطی** - مسیر دهی به عوامل متخصص مختلف بر اساس شرایط.

**انسان در حلقه** - الگوی گردش کار که نقاط بررسی انسانی برای تایید یا بازبینی محتوا اضافه می‌کند.

**langchain4j-agentic** - وابستگی مِیون برای ساخت عامل‌های اظهاری (آزمایشی).

**گردش کار حلقه‌ای** - اجرای مکرر عامل تا رسیدن به یک شرط (مثلاً امتیاز کیفیت ≥ ۰.۸).

**outputKey** - پارامتر علامت‌گذاری عامل که مشخص می‌کند نتایج کجا در دامنه عاملی ذخیره شوند.

**گردش کار موازی** - اجرای چند عامل به طور همزمان برای وظایف مستقل.

**استراتژی پاسخ** - چگونگی فرمولاسیون پاسخ نهایی توسط ناظر: آخرین، خلاصه یا امتیازدهی شده.

**گردش کار ترتیبی** - اجرای عوامل به ترتیب که خروجی به مرحله بعدی انتقال می‌یابد.

**الگوی عامل ناظر** - الگوی پیشرفته عاملی که در آن یک LLM ناظر به طور پویا تصمیم می‌گیرد کدام زیرعامل‌ها را فراخوانی کند.

## پروتکل زمینه مدل (MCP) - [ماژول ۰۵](../05-mcp/README.md)

**langchain4j-mcp** - وابستگی مِیون برای ادغام MCP در LangChain4j.

**MCP** - پروتکل زمینه مدل: استانداردی برای اتصال برنامه‌های AI به ابزارهای خارجی. یک بار بسازید، همه جا استفاده کنید.

**مشتری MCP** - برنامه‌ای که به سرورهای MCP متصل می‌شود تا ابزارها را کشف و استفاده کند.

**سرور MCP** - خدماتی که ابزارها را از طریق MCP با شرح‌های واضح و ساختار پارامترها ارائه می‌دهد.

**McpToolProvider** - جزء LangChain4j که ابزارهای MCP را برای استفاده در خدمات AI و عامل‌ها بسته‌بندی می‌کند.

**McpTransport** - رابط برای ارتباط MCP. پیاده‌سازی‌ها شامل Stdio و HTTP است.

**ترابری Stdio** - ترابری فرآیند محلی از طریق stdin/stdout. برای دسترسی به سیستم فایل یا ابزارهای خط فرمان مفید است.

**StdioMcpTransport** - پیاده‌سازی LangChain4j که سرور MCP را به عنوان زیرفرآیند اجرا می‌کند.

**کشف ابزار** - مشتری از سرور درباره ابزارهای موجود با شرح‌ها و ساختارها پرس‌وجو می‌کند.
