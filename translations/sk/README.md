## Vzdelávacia cesta

**Nový v LangChain4j?** Pozrite si [Slovník](docs/GLOSSARY.md) pre definície kľúčových pojmov a konceptov.

> **Rýchly štart**

1. Vytvorte fork tohto repozitára do svojho účtu GitHub
2. Kliknite na **Code** → kartu **Codespaces** → **...** → **New with options...**
3. Použite predvolené nastavenia – tým sa vyberie vývojové kontajner vytvorené pre tento kurz
4. Kliknite na **Create codespace**
5. Počkajte 5-10 minút, kým bude prostredie pripravené
6. Ihneď prejdite na [Úvod](./01-introduction/README.md) a začnite!

Po dokončení modulov preskúmajte [Sprievodcu testovaním](docs/TESTING.md), kde uvidíte koncepty testovania LangChain4j v praxi.

> **Poznámka:** Tento tréning používa Azure OpenAI. Začnite s [ZDARMA Azure účtom](https://aka.ms/azure-free-account), ak ho ešte nemáte.

**Ako používať:** Otvorte ľubovoľný kódový súbor a položte Copilotovi navrhované otázky. Má úplný kontext zdrojového kódu a vie vysvetľovať, rozširovať a navrhovať alternatívy.
