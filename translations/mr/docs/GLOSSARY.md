## कोर संकल्पना

**AI एजंट** - AI वापरून स्वायत्त विचार करणारी व कृती करणारी प्रणाली. [मॉड्यूल 04](../04-tools/README.md)

**चेन** - ऑपरेशन्सची साखळी ज्यात आउटपुट पुढील स्टेपमध्ये जाते.

**चंकिंग** - दस्तऐवज छोटे भागांमध्ये विभाजित करणे. सामान्य: 300-500 टोकनसह ओव्हरलॅप. [मॉड्यूल 03](../03-rag/README.md)

**कॉन्टेक्स्ट विंडो** - मॉडेल प्रक्रिया करू शकणाऱ्या टोकन्सचा कमाल मार्जिन. GPT-5.2: 400K टोकन्स (जास्तीत जास्त 272K इनपुट, 128K आउटपुट).

**एम्बेडिंग्ज** - मजकुराचा अर्थ दर्शवणारे संख्यात्मक वेक्टर. [मॉड्यूल 03](../03-rag/README.md)

**फंक्शन कॉलिंग** - मॉडेल बाह्य फंक्शन्स कॉल करण्यासाठी रचनेत विनंत्या तयार करते. [मॉड्यूल 04](../04-tools/README.md)

**हेलुसिनेशन** - जेव्हा मॉडेल चुकीची पण संभाव्य माहिती निर्माण करतात.

**प्रॉम्प्ट** - भाषेच्या मॉडेलनुसार इनपुट मजकूर. [मॉड्यूल 02](../02-prompt-engineering/README.md)

**सिमँटिक सर्च** - एम्बेडिंग्ज वापरून अर्थानुसार शोध, कीवर्ड न वापरता. [मॉड्यूल 03](../03-rag/README.md)

**स्टेटफुल विरुद्ध स्टेटलेस** - स्टेटलेस: स्मृती नाही. स्टेटफुल: संभाषण इतिहास राखतो. [मॉड्यूल 01](../01-introduction/README.md)

**टोकन्स** - मॉडेल प्रक्रिया करणारे मूलभूत मजकूर घटक. खर्च आणि मर्यादा प्रभावित करतात. [मॉड्यूल 01](../01-introduction/README.md)

**टूल चेनिंग** - एकाप्रमाणे टूल्सच्या अनुक्रमे अंमलबजावणी ज्यात आउटपुट पुढील कॉलसाठी वापरले जाते. [मॉड्यूल 04](../04-tools/README.md)

## LangChain4j घटक

**AiServices** - प्रकार-सुरक्षित AI सेवा इंटरफेसेस तयार करतो.

**OpenAiOfficialChatModel** - OpenAI आणि Azure OpenAI मॉडेल्ससाठी एकात्मिक क्लायंट.

**OpenAiOfficialEmbeddingModel** - OpenAI अधिकृत क्लायंट वापरून एम्बेडिंग्ज तयार करतो (दोन्ही OpenAI आणि Azure OpenAI समर्थित).

**ChatModel** - भाषिक मॉडेलसाठी मुख्य इंटरफेस.

**ChatMemory** - संभाषण इतिहास टिकवून ठेवतो.

**ContentRetriever** - RAG साठी संबंधित दस्तऐवज चंक्स शोधतो.

**DocumentSplitter** - दस्तऐवज चंक्समध्ये विभाजित करतो.

**EmbeddingModel** - मजकूर संख्यात्मक वेक्टरमध्ये रूपांतरित करतो.

**EmbeddingStore** - एम्बेडिंग्ज साठवतो आणि पुनर्प्राप्त करतो.

**MessageWindowChatMemory** - अलीकडील संदेशांचे स्लायडिंग विंडो राखतो.

**PromptTemplate** - `{{variable}}` प्लेसहोल्डरसह पुनर्वापरयोग्य प्रॉम्प्ट तयार करतो.

**TextSegment** - मेटाडेटा असलेला मजकूर चंक. RAG मध्ये वापरला जातो.

**ToolExecutionRequest** - टूल अंमलबजावणीची विनंती दर्शवतो.

**UserMessage / AiMessage / SystemMessage** - संभाषण संदेश प्रकार.

## AI/ML संकल्पना

**फ्यू-शॉट लर्निंग** - प्रॉम्प्टमध्ये उदाहरणे देणे. [मॉड्यूल 02](../02-prompt-engineering/README.md)

**लार्ज लँग्वेज मॉडेल (LLM)** - मोठ्या प्रमाणावर मजकूर डेटा वापरून AI मॉडेल्स.

**रिझनिंग एफर्ट** - GPT-5.2 मध्ये विचार करण्याची खोली नियंत्रित करणारा पॅरामिटर. [मॉड्यूल 02](../02-prompt-engineering/README.md)

**टेम्परेचर** - आउटपुट विरुद्ध यादृच्छिकतेवर नियंत्रण ठेवतो. कमी=नियत, जास्त=सर्जनशील.

**व्हेक्टर डेटाबेस** - एम्बेडिंग्जसाठी खास डेटाबेस. [मॉड्यूल 03](../03-rag/README.md)

**झिरो-शॉट लर्निंग** - कोणतीही उदाहरणे न देता कामे करणं. [मॉड्यूल 02](../02-prompt-engineering/README.md)

## गार्डरेल्स

**डीफेन्स इन डेप्थ** - मल्टी-लेयर सुरक्षा दृष्टीकोन ज्यात अ‍ॅप्लिकेशन-लेव्हल गार्डरेल्स आणि प्रदाता सुरक्षा फिल्टर्स यांचा समावेश आहे.

**हार्ड ब्लॉक** - गंभीर सामग्री उल्लंघनांसाठी प्रदाता HTTP 400 त्रुटी देते.

**InputGuardrail** - LangChain4j इंटरफेस जे वापरकर्त्याचा इनपुट LLM पर्यंत पोहोचण्यापूर्वी वैधता तपासते. हानिकारक प्रॉम्प्ट्स लवकर ब्लॉक करून खर्च आणि विलंब कमी करते.

**InputGuardrailResult** - गार्डरेल वैधतेसाठी परतावा प्रकार: `success()` किंवा `fatal("कारण")`.

**OutputGuardrail** - AI प्रतिसादांना वापरकर्त्यांना परत देण्यापूर्वी वैध करण्यासाठी इंटरफेस.

**Provider Safety Filters** - AI प्रदात्यांकडून (उदा. Azure OpenAI) अंगभूत कंटेंट फिल्टर्स जे API स्तरावर उल्लंघने पकडतात.

**Soft Refusal** - मॉडेल आदरपूर्वक उत्तर देण्यास नकार देते पण त्रुटी टाकत नाही.

**सेल्फ-रिफ्लेक्शन** - मॉडेल स्वतःच्या आउटपुटचे मूल्यांकन व सुधारणा करतो.

## एजंटिक मॉड्यूल - [मॉड्यूल 05](../05-mcp/README.md)

**@Agent अनुलेखन** - इंटरफेसेसना AI एजंट्स म्हणून चिन्हांकित करते ज्यात घोषणात्मक वर्तन परिभाषित आहे.

**एजंट लिसनर** - `beforeAgentInvocation()` आणि `afterAgentInvocation()` द्वारे एजंट अंमलबजावणी निरीक्षणासाठी हुक.

**एजंटिक स्कोप** - सामायिक स्मृती जिथे एजंट आउटपुट `outputKey` वापरून साठवतात ज्याचा वापर जवळच्या एजंट्स करतात.

**AgenticServices** - `agentBuilder()` आणि `supervisorBuilder()` वापरून एजंट तयार करण्यासाठी फॅक्टरी.

**कंडिशनल वर्कफ्लो** - भिन्न विशेषज्ञ एजंटना परिस्थितीनुसार मार्गदर्शन.

**मानव-मध्यस्त** - मानवी तपासणी व मंजुरीसाठी मानवी तपासणी टप्पा असलेला वर्कफ्लो.

**langchain4j-agentic** - घोषणात्मक एजंट बनवण्यासाठी मावेन डिपेंडेंसी (प्रायोगिक).

**लूप वर्कफ्लो** - एखादी अट पूर्ण होईपर्यंत एजंट पुनरावृत्ती (उदा. गुणवत्ता स्कोअर ≥ 0.8).

**outputKey** - एजंट अनुलेखन पॅरामीटर जे एजंटिक स्कोपमध्ये निकाल कसे साठवायचे ते सांगते.

**पॅरेलल वर्कफ्लो** - स्वतंत्र कामांसाठी एकाच वेळी अनेक एजंट्स चालवा.

**प्रतिक्रिया धोरण** - सुपरवायझर अंतिम उत्तर कसे तयार करतो: LAST, SUMMARY, किंवा SCORED.

**अनुक्रमे वर्कफ्लो** - एजंट्स क्रमाने चालवा ज्यात आउटपुट पुढच्या स्टेपसाठी जाते.

**सुपरवायझर एजंट पॅटर्न** - प्रगत एजंटिक नमुना जेथे सुपरवायझर LLM गतिशीलपणे कोणते उप-एजंट्स कॉल करायचे ठरवतो.

## मॉडेल कॉन्टेक्स्ट प्रोटोकॉल (MCP) - [मॉड्यूल 05](../05-mcp/README.md)

**langchain4j-mcp** - LangChain4j मध्ये MCP एकत्रीकरणासाठी मावेन डिपेंडेंसी.

**MCP** - मॉडेल कॉन्टेक्स्ट प्रोटोकॉल: AI ऍप्सना बाह्य टूल्सशी जोडण्यासाठी मानक. एकदा बनवा, सगळीकडे वापरा.

**MCP क्लायंट** - MCP सर्वरशी जोडणारा ऍप्लिकेशन जो टूल्स शोधतो व वापरतो.

**MCP सर्व्हर** - MCP द्वारे टूल्स स्पष्ट वर्णन आणि पॅरामीटर स्कीमासह उपलब्ध करून देणारी सेवा.

**McpToolProvider** - LangChain4j घटक जो MCP टूल्सना AI सेवा व एजंट्समध्ये वापरण्यासाठी वापरतो.

**McpTransport** - MCP संवादासाठी इंटरफेस. अंमलबजावणीमध्ये Stdio आणि HTTP समाविष्ट.

**Stdio ट्रान्सपोर्ट** - stdin/stdout द्वारे लोकल प्रोसस ट्रान्सपोर्ट. फाइलसिस्टम प्रवेश किंवा कमांड-लाइन टूलसाठी उपयुक्त.

**StdioMcpTransport** - LangChain4j अंमलबजावणी जी MCP सर्व्हर उपप्रक्रिया म्हणून चालवते.

**टूल शोध** - क्लायंट उपलब्ध टूल्ससाठी वर्णन आणि स्कीमांसह सर्व्हरला क्वेरी करतो.
