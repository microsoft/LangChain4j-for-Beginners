## அடிப்படை கருத்துக்கள்

**AI Agent** - AIயைப் பயன்படுத்தி தானாகக் க்கூறிவிட்டு செயல் படுத்தும் அமைப்பு. [Module 04](../04-tools/README.md)

**Chain** - ஒவ்வொரு படியிலும் வெளிப்படும் நுழைவு அடுத்து செயலுக்கு வழங்கப்படும் செயல்முறை தொடர்ச்சி.

**Chunking** - ஆவணங்களை சிறிய துண்டுகளாகப் பிரித்தல். வழக்கம்: 300-500 குறியீடுகள் ஒட்டுமொத்தம். [Module 03](../03-rag/README.md)

**Context Window** - ஒரு மாடல் செயலாக்கக்கூடிய அதிகபட்ச குறியீடுகள். GPT-5.2: 400K குறியீடுகள் (முழுதியும் 272K உள்ளீடு, 128K வெளியீடு).

**Embeddings** - உரையின் பொருளை பிரதிபலிக்கும் இலக்கண எண்கோவைகள். [Module 03](../03-rag/README.md)

**Function Calling** - மாடல் வெளிப்படும் அமைப்புடன் வெளிப்புற செயல்பாடுகளை அழைக்கும் கோரிக்கைகளை உருவாக்கும். [Module 04](../04-tools/README.md)

**Hallucination** - மாடல்கள் தவறான ஆனால் நம்பத்தகுந்த தகவல்களை உருவாக்கும் நிலை.

**Prompt** - மொழி மாடலுக்கு வழங்கப்படும் உரை உள்ளீடு. [Module 02](../02-prompt-engineering/README.md)

**Semantic Search** - பொருள் வைத்து தேடல், முக்கியச்சொற்கள் அல்லாமல் embeddings களைப் பயன்படுத்துதல். [Module 03](../03-rag/README.md)

**Stateful vs Stateless** - Stateless: நினைவாற்றல் இல்லாதது. Stateful: உரையாடல் வரலாற்றை வைத்திருக்கும். [Module 01](../01-introduction/README.md)

**Tokens** - மாடல்கள் செயலாக்கும் அடிப்படைக் கட்டிகள். செலவுகள் மற்றும் வரம்புகளை பாதிக்கும். [Module 01](../01-introduction/README.md)

**Tool Chaining** - கருவிகள் தொடர் முறையில் செயல்படும் போது ஒன்றின் வெளியீடு அடுத்தஅழைப்பிற்கு தகவல் அளிக்கும். [Module 04](../04-tools/README.md)

## LangChain4j கூறுகள்

**AiServices** - வகை-பாதுகாப்பான AI சேவை இடைமுகங்களை உருவாக்குகிறது.

**OpenAiOfficialChatModel** - OpenAI மற்றும் Azure OpenAI மாடல்களுக்கு ஒன்றிய காயகளர்ப்புக் கிளையன்.

**OpenAiOfficialEmbeddingModel** - OpenAI அதிகாரப்பூர்வ கிளையனைப் பயன்படுத்தி embeddings உருவாக்குதல் (OpenAI மற்றும் Azure OpenAI இரண்டும் ஆதரிக்கப்படுகிறது).

**ChatModel** - மொழி மாடல்களுக்கான மைய இடைமுகம்.

**ChatMemory** - உரையாடல் வரலாற்றை வைத்திருக்கும்.

**ContentRetriever** - RAGக்கான பொருத்தமான ஆவண துண்டுகளை கண்டுபிடிக்கும்.

**DocumentSplitter** - ஆவணங்களை துண்டுகளாகப் பிரிக்கும்.

**EmbeddingModel** - உரையை இலக்கண எண்கோவைகளாக மாற்றும்.

**EmbeddingStore** - embeddings களை சேமித்து மீட்டெடுக்கிறது.

**MessageWindowChatMemory** - சமீபத்திய செய்திகளின் செலுத்தும் சாளரத்தை பராமரிக்கும்.

**PromptTemplate** - `{{variable}}` இடமிருந்து மீட்கக்கூடிய ப்ராம்ட்கள் உருவாக்குகிறது.

**TextSegment** - உள்குறிப்புடன் கூடிய உரை துண்டு. RAG இல் பயன்படும்.

**ToolExecutionRequest** - கருவி செயல்பாடல் கோரிக்கை.

**UserMessage / AiMessage / SystemMessage** - உரையாடல் செய்தி வகைகள்.

## AI/ML கருத்துக்கள்

**Few-Shot Learning** - ப்ராம்ட்களில் எடுத்துக்காட்டுகளை வழங்குதல். [Module 02](../02-prompt-engineering/README.md)

**Large Language Model (LLM)** - பெரும் உரைத் தரவுகளின் அடிப்படையில் பயிற்சிப் பெற்ற AI மாடல்கள்.

**Reasoning Effort** - GPT-5.2 இல் எண்ணும் ஆழத்தைக் கட்டுப்படுத்தும் அளவுரு. [Module 02](../02-prompt-engineering/README.md)

**Temperature** - வெளிப்பாட்டின் சீராக்காமல் மாறுபாட்டைக் கட்டுப்படுத்தும். குறைந்தது=தெளிவானது, அதிகம்=புதுமையாக.

**Vector Database** - embeddings க்கான சிறப்பு தரவுத்தளம். [Module 03](../03-rag/README.md)

**Zero-Shot Learning** - எடுத்துக்காட்டுகள் இல்லாமல் பணிகள் செய்யுதல். [Module 02](../02-prompt-engineering/README.md)

## காவல் கோடுகள்

**Defense in Depth** - பயன்பாட்டு மட்டத்தில் காவல் கோடுகளை வழங்கி சேவையக பாதுகாப்பு சான்றுகள் மற்றும் பகிரங்க பாதுகாப்பு வடிகட்டிகளுடன் இணைத்தல்.

**Hard Block** - கடுமையான உள்ளடக்க மீறல்களுக்கு சேவையகம் HTTP 400 பிழை எழுப்பும்.

**InputGuardrail** - LangChain4j இடைமுகம், பயனரின் உள்ளீட்டை LLM க்கு செல்லும் முன் சரிபார்த்து சேமிக்கும். ஆபத்தான ப்ராம்ட்களை முதலில் தடுக்கச் செலவு மற்றும் தாமதத்தை குறைக்கும்.

**InputGuardrailResult** - காவல் மதிப்பீட்டிற்கான பின்வருங்கள் வகை: `success()` அல்லது `fatal("காரணம்")`.

**OutputGuardrail** - பயனர்களுக்கு பதிலளிக்கும் முன் AI பதில்களை சரிபார்க்கும் இடைமுகம்.

**Provider Safety Filters** - AI வழங்குநர்களால் (உதா. Azure OpenAI) வழங்கப்படும் உள்ளடக்க வடிகட்டிகள், API நிலை மீது மீறல்களை பிடிக்கும்.

**Soft Refusal** - பிழை இல்லாமல் மாடல் நெகிழ்வாக பதில் மறுக்கும்.

## ப்ராம்ட் பொறியியல் - [Module 02](../02-prompt-engineering/README.md)

**Chain-of-Thought** - படிப்படியாக காரணம் காட்டுதல், நிறைவான சரியான பதிலுக்கு.

**Constrained Output** - இடையறாத குறிப்பான வடிவமைப்பு அல்லது கட்டமைப்பை வலியுறுத்துதல்.

**High Eagerness** - GPT-5.2 இல் விரிவான காரணவியல் மாதிரி.

**Low Eagerness** - GPT-5.2 இல் வேகமாக பதில் அளிக்கும் மாதிரி.

**Multi-Turn Conversation** - பரிமாற்றங்களில் சுருட்டு நிலைகளை பராமரித்தல்.

**Role-Based Prompting** - அமைப்பு செய்திகளால் மாடல் தனிப்பட்ட வசந்தம் அமைத்தல்.

**Self-Reflection** - மாடல் தனது வெளிப்பாட்டை மதிப்பாய்ந்து மேம்படுத்துதல்.

**Structured Analysis** - நிர்ணயிக்கப்பட்ட மதிப்பீட்டு கட்டமைப்பு.

**Task Execution Pattern** - திட்டமிடு → செயல் → சுருக்கம்.

## RAG (Retrieval-Augmented Generation) - [Module 03](../03-rag/README.md)

**Document Processing Pipeline** - ஏற்றவும் → துண்டாக்கவும் → உள்வெள்ளை உருவாக்கவும் → சேமிக்கவும்.

**In-Memory Embedding Store** - சோதனைகளுக்கான தற்காலிக சேமிப்பு.

**RAG** - மீட்டெடுக்கும் மற்றும் உருவாக்கும் ஒன்று சேர்க்கை, பதில்களை ஆதாரமாக்கும்.

**Similarity Score** - பொருள் ஒத்திசைவு அளவு 0-1 வரை.

**Source Reference** - மீட்டெடுக்கப்பட்ட உள்ளடக்கத்தின் உள் குறிப்புகள்.

## செயலாளர்கள் மற்றும் கருவிகள் - [Module 04](../04-tools/README.md)

**@Tool Annotation** - ஜாவா முறைகளை AI அழைக்கக்கூடிய கருவியாகக் குறிக்கிறது.

**ReAct Pattern** - காரணம் → செயல் → கவனிக்கவும் → மீண்டும்.

**Session Management** - வேறு பயனர்களுக்கான தனித்தனித் சூழல்கள்.

**Tool** - AI செயலாளி அழைக்கக்கூடிய செயல்பாடு.

**Tool Description** - கருவியின் நோக்கு மற்றும் அளவுருக்களின் ஆவணம்.

## ஏஜென்டிக் பிரிவு - [Module 05](../05-mcp/README.md)

**@Agent Annotation** - இடைமுகங்களை AI செயலாளிகளாகவும், அறிவுரை செயலை விளக்கவும் குறிக்கிறது.

**Agent Listener** - `beforeAgentInvocation()` மற்றும் `afterAgentInvocation()` மூலம் செயலாளி செயலை கண்காணிக்க உதவி.

**Agentic Scope** - செயலாளர்கள் வெளியீடுகளை பகிர்ந்து downstream செயலாளிகள் பயன்படுத்தும் பொதுவான நினைவகம்.

**AgenticServices** - `agentBuilder()` மற்றும் `supervisorBuilder()` மூலம் செயலாளிகளை உருவாக்கும் தொழிற்சாலை.

**Conditional Workflow** - விதிமுறைகளின்படி வித்துவாத செயலாளரிடம் வழிமாறு.

**Human-in-the-Loop** - அனுமதி அல்லது உள்ளடக்க பரிசீலனைக்கான மனிதச் சோதனைப்புள்ளிகள் உள்ள பணிமுறை மாதரி.

**langchain4j-agentic** - அறிவுரையுள்ள செயலாளி கட்டமைப்பிற்கு Maven சார்பு (அனுபவபூர்வமானது).

**Loop Workflow** - விகிதம் முந்தைய வரை அல்லது நிபந்தனை பூர்த்தி வரை செயலாளி செயல்பாட்டை மீண்டும் இயக்கு.

**outputKey** - செயலாளிக் குறிக்கோள், Agentic Scope இல் முடிவுகள் சேமிக்கப்படும் இடத்தை குறிப்பிடும்.

**Parallel Workflow** - பல செயலாளிகள் தனித்தனிக் பணிகளுக்கு ஒரே நேரத்தில் இயங்கும்.

**Response Strategy** - மேலாளர் இறுதிப்பதில் பதிலை உருவாக்கும் பாணி: LAST, SUMMARY, அல்லது SCORED.

**Sequential Workflow** - செயலாளர்களை வரிசைப்படி இயக்கு, வெளியீடு அடுத்தபடியான கட்டத்திற்கு செல்கிறது.

**Supervisor Agent Pattern** - மேலாளர் LLM பின்விளைவுகளில் எந்த துணை செயலாளர்களை அழைப்பது என்று நுண்ணறிவுடன் முடிவு செய்யும் உயர் நிலை ஏஜென்டிக் மாதிரி.

## மாடல் வார_CONTEXT_நெறிமுறை (MCP) - [Module 05](../05-mcp/README.md)

**langchain4j-mcp** - LangChain4j இல் MCP ஒருங்கிணைப்புக்கான Maven சார்பு.

**MCP** - மாடல் வார_CONTEXT_நெறிமுறை: வெளிப்புற கருவிகளுடன் AI செயலிகளைக் இணைக்கும் தரநிலை. ஒருமுறை கட்டி, எங்கும் பயன்படுத்து.

**MCP Client** - MCP சேவையகங்களைத் தொடர்பு கொண்டு கருவிகள் தேடவும் பயன்படுத்தவும் பயன்படும் செயலி.

**MCP Server** - தெளிவான விவரங்கள் மற்றும் அளவுரு கட்டமைப்புகளுடன் MCP மூலம் கருவிகளை வெளிப்படுத்தும் சேவை.

**McpToolProvider** - LangChain4j கூறு, MCP கருவிகளை AI சேவைகளிலும் செயலாளர்களிலும் பயன்படுத்துவதற்காக மூடியதாக காட்டும்.

**McpTransport** - MCP தொடர்புக்கான இடைமுகம். நிறைவேற்றல்கள் Stdio மற்றும் HTTP அடங்கும்.

**Stdio Transport** - stdin/stdout மூலம் உள்ளூர் செயலாக்கக் கருவி. கோப்பு அமைப்பிற்கு அணுகுவதற்கோ அல்லது கட்டளைக்குறி கருவிகளுக்கு பயனுள்ளது.

**StdioMcpTransport** - LangChain4j நிறைவேற்றல், MCP சேவையகத்தை துணைசேவையாக இயக்குகிறது.

**Tool Discovery** - கிளையன் சேவையகத்துக்கு கிடைக்கும் கருவிகளின் விவரங்கள் மற்றும் கட்டமைப்புகளைக் கேள்வி செய்கிறது.
