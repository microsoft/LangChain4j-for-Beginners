## Leertraject

**Nieuw bij LangChain4j?** Bekijk de [Glossary](docs/GLOSSARY.md) voor definities van belangrijke termen en concepten.

> **Snelle Start**

1. Fork deze repository naar je GitHub-account
2. Klik op **Code** → tabblad **Codespaces** → **...** → **Nieuw met opties...**
3. Gebruik de standaardinstellingen – hiermee wordt de ontwikkelcontainer geselecteerd die voor deze cursus is gemaakt
4. Klik op **Codespace maken**
5. Wacht 5-10 minuten tot de omgeving klaar is
6. Ga direct naar [Introductie](./01-introduction/README.md) om te beginnen!

Na voltooiing van de modules, bekijk de [Testgids](docs/TESTING.md) om LangChain4j testconcepten in actie te zien.

> **Opmerking:** Deze training maakt gebruik van Azure OpenAI. Begin met een [GRATIS Azure-account](https://aka.ms/azure-free-account) als je er nog geen hebt.


## Leren met GitHub Copilot

Om snel te beginnen met coderen, open je dit project in een GitHub Codespace of je lokale IDE met de meegeleverde devcontainer. De devcontainer die in deze cursus wordt gebruikt, is vooraf geconfigureerd met GitHub Copilot voor AI-geassisteerd programmeren.

Elke codevoorbeeld bevat voorgestelde vragen die je aan GitHub Copilot kunt stellen om je begrip te verdiepen. Let op de 💡/🤖 prompts in:

- **Java-bestand headers** - Vragen specifiek voor elk voorbeeld
- **Module README's** - Verkenningsprompts na codevoorbeelden

**Hoe te gebruiken:** Open elk codebestand en stel Copilot de voorgestelde vragen. Het heeft volledige context van de codebase en kan uitleggen, uitbreiden en alternatieven suggereren.

Wil je meer leren? Bekijk [Copilot voor AI-geassisteerd programmeren](https://aka.ms/GitHubCopilotAI).
