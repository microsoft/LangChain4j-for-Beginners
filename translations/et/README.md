## Õppeteekond

**Uus LangChain4j-s?** Tutvu [Sõnaloendi](docs/GLOSSARY.md) definitsioonidega olulistest terminidest ja kontseptsioonidest.

> **Kiire algus**

1. Forkige see hoidla oma GitHubi kontole
2. Klõpsake **Code** → **Codespaces** vahekaart → **...** → **New with options...**
3. Kasutage vaikevalikuid – see valib arenduskonteineri, mis on kursuse jaoks loodud
4. Klõpsake **Create codespace**
5. Oodake 5–10 minutit, kuni keskkond on valmis
6. Minge otse [Sissejuhatusse](./01-introduction/README.md) alustamiseks!

Moodulite läbimise järel uurige [Testimise juhendit](docs/TESTING.md), et näha LangChain4j testimiskontseptsioonide rakendust.

> **Märkus:** See koolitus kasutab Azure OpenAI. Alustage [TASUTA Azure kontoga](https://aka.ms/azure-free-account), kui teil seda veel pole.


## Õppimine GitHub Copilotiga

Kiireks programmeerimise alustamiseks avage see projekt GitHub Codespaces või oma kohaliku IDE-s pakkudaud devcontaineriga. Selles kursuses kasutatav devcontainer on eelkonfigureeritud GitHub Copilotiga AI paarisprogrammeerimiseks.

Igas koodinäites on soovitatud küsimused, mida võite GitHub Copilotile esitada, et süvendada oma arusaamist. Otsige 💡/🤖 vihjeid:

- **Java failipealkirjades** - küsimused, mis on spetsiifilised iga näite kohta
- **Mooduli README-failides** - uurimisküsimused pärast koodinäiteid

**Kasutusjuhend:** Avage ükskõik milline koodifail ja esitage Copilotile soovitatud küsimused. Tal on täielik ülevaade koodibaasist ning ta saab seletada, laiendada ja pakkuda alternatiive.

Tahad rohkem õppida? Tutvu [Copilot AI paarisprogrammeerimiseks](https://aka.ms/GitHubCopilotAI).
