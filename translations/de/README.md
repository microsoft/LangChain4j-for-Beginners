## Lernpfad

**Neu bei LangChain4j?** Schauen Sie sich das [Glossar](docs/GLOSSARY.md) für Definitionen wichtiger Begriffe und Konzepte an.

> **Schnellstart**

1. Forken Sie dieses Repository in Ihr GitHub-Konto
2. Klicken Sie auf **Code** → **Codespaces**-Tab → **...** → **Neu mit Optionen...**
3. Verwenden Sie die Standardeinstellungen – dies wählt den für diesen Kurs erstellten Entwicklungscontainer aus
4. Klicken Sie auf **Codespace erstellen**
5. Warten Sie 5-10 Minuten, bis die Umgebung bereit ist
6. Springen Sie direkt zur [Einführung](./01-introduction/README.md), um loszulegen!

Nach Abschluss der Module erkunden Sie den [Testleitfaden](docs/TESTING.md), um LangChain4j-Testkonzepte in Aktion zu sehen.

> **Hinweis:** Diese Schulung nutzt Azure OpenAI. Starten Sie mit einem [KOSTENLOSEN Azure-Konto](https://aka.ms/azure-free-account), falls Sie noch keines haben.


## Lernen mit GitHub Copilot

Um schnell mit dem Programmieren zu beginnen, öffnen Sie dieses Projekt in einem GitHub Codespace oder Ihrer lokalen IDE mit dem bereitgestellten Devcontainer. Der im Kurs verwendete Devcontainer ist vorkonfiguriert mit GitHub Copilot für AI-Paarprogrammierung.

Jedes Code-Beispiel enthält empfohlene Fragen, die Sie GitHub Copilot stellen können, um Ihr Verständnis zu vertiefen. Achten Sie auf die 💡/🤖 Hinweise in:

- **Java-Dateiköpfen** - Fragen, die speziell für jedes Beispiel geeignet sind
- **Modul-READMEs** - Erkundungsfragen nach Code-Beispielen

**Wie man es benutzt:** Öffnen Sie eine beliebige Code-Datei und stellen Sie Copilot die vorgeschlagenen Fragen. Es hat den vollständigen Kontext des Codebases und kann erklären, erweitern und Alternativen vorschlagen.

Möchten Sie mehr lernen? Schauen Sie sich [Copilot für AI-Paarprogrammierung](https://aka.ms/GitHubCopilotAI) an.
